# 0027 — Text color shortcuts are Ctrl+Cmd+1…7

**Status:** Accepted (2026-11-03). Resolves PLAN Q4 (#17).

Cmd+1 stays Show Scenes (PLAN §11). Text colors use **Ctrl+Cmd+1…7** in palette order: black (removes the color), purple, red,
blue, green, gray, pink. They're listed in Format → Text Color ▸ with these shortcuts.
