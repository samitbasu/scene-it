## Hand-test checklist (one session)

Everything has been reviewed independently and gated. These are the things agents can't test, because no test can synthesize real input.
Use the trial app built from `main` (path given in the chat), with a throwaway book.

1. **Scenes sheet (⌘1)**
   1. Click into a card's title field and its + tag field. The field should take the click, without opening the scene or closing the sheet.
   2. Type half a tag, scroll the card off screen and back, and see what happened to the text.
2. **Boneyard**
   1. Drag a card to reorder it. The "Move here" slot should hold steady, and there should be no "+" badge.
   2. Drag a card onto the tray: it lights red, and the card is cut.
   3. Drag a tile back onto the grid ("Restore here"), and click ↩.
   4. Drop in a gap, and outside the window. The card should stop being faded at once.
   5. Delete Permanently… on a tile, confirm, then press ⌘Z.
   6. The keys: arrows, Return, Delete, Option+arrows. Also check that the arrows work after Return in a new card's title.
3. **Export as SceneIt…**
   1. It should be enabled with a book open, and disabled on the start screen and while File a Copy is up.
   2. Shift-click a run of scenes in the chooser.
4. **Review Book…** (with the .md from step 3)
   1. Open it from the start screen and through the real open panel.
   2. Typing should be refused. Add comments and a note.
   3. Quit and reopen: the review resumes, and a `.review.md` sits beside the copy.
5. **Copy Review / Save Review…**
   1. Paste into Gmail compose and into Mail. Check the styling, the yellow passage, the ☐ symbols, and the curly quotes and dashes.
   2. Paste into TextEdit as plain text.
   3. Save Review…, then open the file in Safari and Chrome. Tick boxes, reload, and restart the browser; the ticks should still be there.
   4. Try saving over the copy, or without `.html`. It should be refused.
6. **Help → Report a Problem window** (#165): with it open beside the main window, press Esc and Return in the main window. Only the main window should react.
